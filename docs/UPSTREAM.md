The new repository uses an audited clean import, not a claim that upstream code is original. A native GitHub Fork is preferred if it can be established without importing unreviewed upstream history. Otherwise maintain this clearly attributed derivative and contribute focused fixes upstream after separate authorization. No independent market entry is proposed.

The 0.1.2-rc.5 maintenance changes the settings entry and information layout, adds configuration-based expected preview using the same pure selection rules as the Host, and strengthens failed-refresh acknowledgement without changing template data or injection semantics.

The 0.1.3-rc.5 maintenance changes only settings spacing and presentational classes. Upstream attribution and license remain unchanged.

The 0.1.4-rc.5 maintenance by 379385796-sys carries forward the accepted RC5 adaptation and UI, then adds per-Agent three-state template selection, safe legacy-exclusion migration, localized live-roster row settings and targeted request-boundary validation. Earlier unshipped candidates explored exclusions and cards; only the final 0.1.4-rc.5 is published. H1a3x remains the original author.
